## Agent skills

### Issue tracker

Specifikationer och ärenden hanteras som lokala Markdown-filer under `.scratch/<feature>/`. Se `docs/agents/issue-tracker.md`.

### Triage labels

Använd standardetiketterna `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` och `wontfix`. Se `docs/agents/triage-labels.md`.

### Domain docs

Projektet har en gemensam domänkontext: `CONTEXT.md` och `docs/adr/` i roten, när dessa finns. Se `docs/agents/domain.md`.
