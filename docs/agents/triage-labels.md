# Triage Labels

Standardetiketterna godkändes av användaren 2026-10-07.

| Canonical role  | Label in this tracker | Meaning                                                                           |
| --------------- | --------------------- | --------------------------------------------------------------------------------- |
| needs-triage    | needs-triage          | Ärendet behöver bedömas.                                                          |
| needs-info      | needs-info            | Nödvändiga uppgifter saknas.                                                      |
| ready-for-agent | ready-for-agent       | Ärendet är tillräckligt specificerat för en agent när dess blockerare är färdiga. |
| ready-for-human | ready-for-human       | Genomförandet behöver göras av en människa.                                       |
| wontfix         | wontfix               | Ärendet ska inte genomföras.                                                      |

I lokala Markdown-filer lagras triageetiketten på raden `Status:`. Utkaststatus `draft` används före publicering och är inte en ytterligare triageetikett. Genomförandestatus och blockerande beroenden hanteras separat.
